# NAMING.md

## Approved working name

# Hablyra

Pronunciation suggestion:
**hab-LEE-ra** or **HAB-lee-ra**

Recommended brand pronunciation for consistency:
**hab-LEE-ra**

## Why this name

Hablyra is a coined brand name.

It subtly evokes:
- habit
- rhythm
- repetition
- change
- progress

without literally describing the product.

This makes it more ownable and more flexible than generic names such as:
- Habit Tracker
- Hablyra
- Break Habits
- Quit Habit

## Brand fit

Hablyra should feel:
- calm
- modern
- focused
- private
- premium
- non-judgmental

It should not look:
- medical
- addiction-treatment oriented
- childish
- aggressively motivational
- game-like

## Tagline

**Break the loop. Build your progress.**

Alternative store subtitle:
**Track habits. Understand patterns.**

## Preliminary screening

At the time of naming, exact-name searches for "Hablyra" produced no obvious direct match across:
- Google Play search results
- Apple App Store search results
- general web/software searches
- basic web-indexed trademark searches

This is only preliminary screening.

Before public launch, perform formal clearance for target markets and check relevant domains/social handles.
